RENTAL MONITORING APP

Privacy Policy

Effective: 21 August 2026

1. Purpose

Rental Monitoring App is a private productivity tool operated by and for the Google account owner. It monitors authorized Gmail messages for rental-property updates and follow-up items.

2. Google data accessed

The app may access Gmail message metadata and content that the account owner has authorized. This access is used only to search, read, and summarize rental-related correspondence.

3. Use of information

Google user data is used only to provide the monitoring and summarization function requested by the account owner. It is not used for advertising, profiling, or unrelated purposes.

4. Sharing and sale

The app does not sell Google user data. It does not share Google user data with third parties except service providers required to run the owner's private automation, subject to the owner's configuration and applicable safeguards.

5. Storage and security

OAuth credentials are stored in the owner's private local environment. Generated summaries may be stored in the owner's private automation logs or delivered to a private messaging destination selected by the owner. Reasonable technical measures are used to restrict access.

6. Retention and deletion

Data is retained only as needed for the private monitoring workflow and its logs. The owner can delete local data and revoke Google access at any time through Google Account connections.

7. Google API Services disclosure

Rental Monitoring App's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
